# 🍽️ Recipe Recommender

A responsive, single-page web application that helps users discover recipes based on ingredients they have at home.

---

## 📌 Features

- 🔍 **Ingredient-based Search** — Add ingredients you have and get matching recipes instantly
- 📖 **Recipe Detail View** — View full ingredients list, step-by-step instructions, cook time, and meal type
- ❤️ **Favourites** — Save and manage your favourite recipes (stored in local storage)
- 🗂️ **Filter Options** — Filter recipes by meal type and diet preference (Veg / Non-Veg)
- 📝 **User Registration** — Simple registration page for new users
- 💬 **Feedback Modal** — Users can submit ratings and comments
- 📱 **Responsive Design** — Works across desktop and mobile devices
- ♿ **Accessibility Support** — Keyboard navigation and ARIA attributes included
